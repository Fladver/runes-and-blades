# Руны и Клинки — сайт игры

Статический сайт (GitHub Pages): https://fladver.github.io/runes-and-blades/

- `index.html` — главная (режимы, герои, нечисть, скриншоты)
- `guide.html` — как играть (полный справочник)
- `arena.html` — справочник «Арены рун»; данные карт — `data/arena.js`, генерируются из кода игры (`ArenaRun.Core`)
- `faq.html` — частые вопросы и форма вопроса (уходит на игровой сервер `/api/ask`)
- `updates.html` — история версий, `privacy.html` — политика конфиденциальности (ссылка в карточке RuStore)

Старый адрес `fladver.github.io/castle-defenders/` переадресует сюда (репозиторий `castle-defenders` хранит релизы APK
и нужен проверке обновлений в игре — не удалять).
